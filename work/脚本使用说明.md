# 脚本使用说明

按角色声纹剪辑动画片段。所有脚本位于 `work/`，路径统一由 `work/core/paths.py` 推导，整个项目目录可整体搬移。

## 环境

| 项目 | 位置 |
|---|---|
| Python 解释器 | `.venv/Scripts/python.exe`（Python 3.12） |
| 语音识别模型 | `models/models--Systran--faster-whisper-large-v3` |
| 声纹模型 | `models/spkrec-ecapa-voxceleb` |
| ffmpeg | `tools/ffmpeg/bin/ffmpeg.exe` |
| 源视频 | `input/` |

运行方式（在 `work/` 目录下）：

```bash
../.venv/Scripts/python.exe -u 脚本名.py
```

全部脚本都支持 `--video`，省略时自动取 `input/` 下第一个视频。**不需要再手工改代码里的路径或编号。**

## 流水线

| 步骤 | 脚本 | 产物（在 `work/jobs/<源ID>/`） | 耗时 |
|---|---|---|---|
| 1 | `extract_audio.py` | `audio16k.wav` | ~10 秒 |
| 2 | `transcribe.py` | `transcript.json` + `manifest.json` | ~2.5 分钟（GPU） |
| 3 | `voiceprint.py` | `embeddings.npz` | ~15 秒 |
| 4 | `select.py` | `selected.json` | ~1 秒 |
| 5 | `cut.py` | `output/<源名>_<角色>_clip.mp4` | ~1 分钟（4K） |
| 6 | `gen_report.py` | `output/<源名>_<角色>_清单.html/.csv` | ~1 秒 |

辅助脚本：`verify.py`（环境自检）、`eval_threshold.py`（阈值评估）、`import_legacy.py`（手动导入旧缓存）。

## 任务目录与运行状态

每个源视频对应 `work/jobs/<文件名>-<内容指纹>/`，指纹是大小加首尾各 1 MiB 的 SHA-256，同名同大小但内容不同的文件不会互相污染。

```
work/jobs/re0_1_08-7828987381905c07/
├── manifest.json              源身份 + 运行记录
├── audio16k.wav
├── selected.json              切点方案
└── runs/20261023-111240-72ee95/
    ├── transcript.json
    └── embeddings.npz
```

分析分三阶段提交：`running` → `transcribed` → `complete`。声纹阶段结束会校验两份产物是否自洽（声纹 ID 必须都能在转写里找到、维度 192、来源一致），通过才标记 `complete` 并设为 `active_run`。

**只有 `complete` 的活动运行会被读取。** 转写成功但声纹失败时，这次运行停在 `transcribed`，不会被当成完整结果使用。

旧版扁平缓存（`work/transcript.json`）不自动迁移——它没有来源指纹，无法判断属于哪个视频。需要手动确认：

```bash
python import_legacy.py --yes
```

## 各脚本说明

### extract_audio.py

```bash
python extract_audio.py                       # 默认 input/ 下第一个视频
python extract_audio.py --video D:/其他.mp4
```

抽第 1 条音轨转 16 kHz 单声道，视频本体不动。

### transcribe.py

```bash
python transcribe.py                          # 默认 large-v3 + cuda
python transcribe.py --model medium --device cpu
```

- `cuda` 初始化失败会自动回退 CPU，日志打印 `[warn]`，与 README 承诺一致
- 只读本地模型（`local_files_only=True`），不会联网下载
- 针对动画的调优：`condition_on_previous_text=False` 抑制 BGM 导致的重复幻觉，`word_timestamps=True` 保留词级时间戳，`vad_filter=True` 过滤纯音乐段

### voiceprint.py

```bash
python voiceprint.py              # 只提声纹，主流程
python voiceprint.py --cluster    # 附带聚类诊断
```

主流程只产出 `embeddings.npz`。聚类已移出主流水线——它在动画素材上效果不稳定（轮廓系数约 0.06），且不影响角色判定，只作为 `--cluster` 的可选观察项。

### select.py

```bash
python select.py --role 碧翠丝                                # 特征词自动挑选 + 阈值筛选
python select.py --role 碧翠丝 --selected-ids 132,133,137     # 精确指定要保留的台词
python select.py --role 碧翠丝 --selected-ids 132,133 --seed-ids 132,133  # 同时指定模板种子
```

参数：`--role`、`--selected-ids`（旧名 `--ids` 仍兼容）、`--seed-ids`、`--keyword`、`--threshold`（默认 0.66）、`--merge-gap`、`--pad-head`、`--pad-tail`。

"要保留哪些台词"和"用什么建立声纹模板"是两个概念，这里分开：

- 自动模式：特征词命中 → 建模板 → 全片打分 → 按阈值筛选
- 显式 `--selected-ids`：只按给定编号选，**不再偷偷套用默认特征词**。没给 `--seed-ids` 就不生成相似度分数，避免用错角色的模板打分

合并规则：

- 相邻台词间隔 ≤ `merge-gap` 且中间没有其他角色插话 → 合并
- 每段前后留出呼吸空间，会自动避让相邻的其他角色语段
- 短于 0.6 秒的碎片按原始边界回退

### cut.py

```bash
python cut.py                                  # 默认保持源规格
python cut.py --scale 1920:1080 --crf 20       # 缩到 1080p
python cut.py --output D:/out.mp4              # 指定输出（相对路径会转绝对路径）
```

采用**单次 filter graph 编码**：所有片段作为独立输入 seek 到各自位置，经 `setpts/asetpts` 归零后在 concat filter 里拼接，只做一次编码。避免"每段分别编码再流复制拼接"的 AAC 延迟与时间戳累积。

- 切点先吸附到帧网格再编码，保证每段是整数帧
- 默认 `--scale native`：不缩放、不强制帧率
- 显式缩放用 `force_original_aspect_ratio=decrease` 加黑边补齐
- 编码完成后会打印计划时长与实际视频流时长的偏差，超过 50 ms 会告警
- 最终文件先写 `.tmp.mp4`，成功后才替换正式文件

### gen_report.py

```bash
python gen_report.py
```

标题、原片时长、保留比例、文件名全部来自 `selected.json` 与 `manifest.json`，不再写死作品和角色。文件名格式 `<源名>_<角色>_清单.html`，不同任务不会互相覆盖。

### verify.py

```bash
python verify.py
```

逐项检查：目录结构、ffmpeg、模型文件、源视频探测、whisper 加载（含 CPU 回退）、ECAPA 加载、切点合法性。探针音频从源视频临时截取，不依赖仓库里的固定文件。任何一项失败返回退出码 1。

### eval_threshold.py

```bash
python eval_threshold.py
```

用人工标注集评估不同阈值下的 precision / recall / F1，并对比稳健模板与简单平均的效果。修改算法或换角色后，先跑这个确认指标没有回退。

### import_legacy.py

```bash
python import_legacy.py           # 先看时长对比，不会写入
python import_legacy.py --yes     # 确认归属后导入
```

旧版把产物直接放在 `work/` 下，没有来源记录。这类文件无法自动判断属于哪个视频，所以只提供手动导入。脚本会先打印源视频与旧转写的时长，不匹配直接拒绝；加 `--yes` 才会建立运行并校验。

## 常见改动

**只重切某几段**（不重新转写，最省时间）
改 `select.py` 的 `--ids`，或直接在 GUI 里勾选 → 跑 `cut.py` → 跑 `gen_report.py`，约 1 分钟。

**调整片段疏密**
- 更连贯：调大 `--merge-gap`（如 3.5）
- 更紧凑：调小 `--merge-gap`（如 1.0）、减小 `--pad-*`
- 避免带入别人尾音：减小 `--pad-tail`

**换一集处理**
1. 视频放进 `input/`
2. 跑 1→2→3，任务目录会自动建立
3. 跑 `eval_threshold.py` 或看 GUI 的分数分布，确定特征词和阈值
4. 跑 `select.py` → `cut.py` → `gen_report.py`

## 注意事项

- **装包用** `.venv/Scripts/python.exe -m pip install xxx`。直接调 `Scripts/pip.exe` 会失败——venv 移动过，pip.exe 里内嵌的旧路径已失效。
- **不要升级 `av`**。faster-whisper 1.2.1 与 `av>=15` 不兼容；本项目用 scipy 读 WAV 后直接传 numpy 数组，绕开了 av 解码。
- **不要覆盖** `models/spkrec-ecapa-voxceleb/hyperparams.yaml`。该文件已删掉 `label_encoder` 加载项，旧格式与新 speechbrain 不兼容。
- **GPU 需要 cuDNN 9**。当前机器可用；换机器若无 CUDA，转写自动降级 CPU，25 分钟音频约需 10–15 分钟。
